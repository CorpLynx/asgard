# Independent review: Baldur's auto-approve and scheduled refresh (2026-10-11)

Asgard's rule: anything that changes estimates, approvals or posting gets an independent review
before it is called done, by a fresh agent with no stake in the code, which tries to break it with
scripts it runs (`AGENTS.md`, Definition of done). Auto-approve is the first feature that lets a
figure reach Jira without a person looking at that day, so it got one.

The reviewer was given the eight guarantees the design claims and told to break each one. It wrote
throwaway harnesses over `tests/test_baldur.py`'s `MuninnCase`, generated real commits and calendar
data, and ran them. Ten findings, all confirmed. Each is fixed below with the repro as a test.

## What held

Verified by the reviewer's own scripts, and worth keeping true:

- **An AI's figure is never auto-approved.** An agent estimate that differs holds the day; when it
  agrees, the engine's own `minutes_proposed` is what gets approved. `desk.approve_day` is called
  without `take_ai`, so `assist.approve_day` is never reached, and a stored-but-not-taken review
  can't produce a "Reviewed:" line in Odin's comment.
- **The five flags already in the list match the strings `estimate.py` really produces.** The
  prefix mismatch this was most at risk of did not exist; the gap was the flags that were missing.
- **The age and cap boundaries are right.** Ages 0 and 1 are held and age 2 qualifies with the
  default; eight waiting days with a cap of 5 approve exactly the oldest 5, and held days don't
  consume the cap.
- **It never raises and never approves untracked time.** `minutes_final == minutes_proposed` in
  every run, and untracked rows can't be approved at all.
- **Both switches are needed**, and argparse's `allow_abbrev=False` means `--a`, `--auto` and
  `--auto-approve=true` are all refused, so the guard's prefix matching has no gap.
- A non-bool `auto_approve` (`"true"`, `1`, `[true]`) can never read as on, and Ysildir exposes no
  approve tool, so there is no MCP path to this.
